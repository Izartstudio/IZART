# Izart case studies

Next.js App Router + TypeScript + Sanity-ready project content. Server-rendered hero with an optional uploaded logo, followed by up to 30 ordered full-width image/video panels. No content overlays or image grids are generated by the code.

## Local preview

```sh
npm ci
npm run dev
```

Visit http://localhost:3000/projects/seraano. Root redirects to this design preview. `/projects/wg1` uses the same template with hero facts pending its asset upload.

```sh
npm run check
```

Runs lint, type checking and a production build. Requires Node 22+. Dependencies are locked in package-lock.json.

## Editing

Until Sanity is connected, edit `src/content/local-projects.ts`. Images and their dimensions are in `src/content/seraano-assets.json`. Hero logo is an optional image object with url, width and height; an absent logo renders nothing. No imitation wordmark is used. The exact font file is pending.

[Connect Sanity](docs/SANITY.md). Schema: `src/sanity/schemaTypes/project.ts`. Public pages load published documents on the server and revalidate every 60 seconds. Sanity Studio is separate (`npm run studio`) so its JavaScript is not shipped to visitors.
